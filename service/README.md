# Сервис для инференса модели Qwen2.5-VL-3B с LoRA

Streamlit-приложение для генерации описаний изображений с использованием дообученной модели Qwen2.5-VL-3B-Instruct.

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Подготовка весов модели

### Вариант 1: Автоматическая загрузка с Google Drive (рекомендуется)

Создайте скрипт для загрузки весов:

```bash
# Установите gdown для загрузки с Google Drive
pip install gdown

# Загрузите папку с весами
gdown --folder https://drive.google.com/drive/folders/18iMs3Niqf0ZXyYGuzDN3Zv7Ro3cBGv3_

# Переместите веса в нужное место
# (укажите правильный путь в соответствии со структурой вашего проекта)
```

### Вариант 2: Ручная загрузка

1. Скачайте веса с [Google Drive](https://drive.google.com/drive/folders/18iMs3Niqf0ZXyYGuzDN3Zv7Ro3cBGv3_)
2. Распакуйте их в директорию `../results/qwen-vl-regional/exp_r=16_alpha=32_seq=256_ne=25/checkpoint-430`
3. Убедитесь, что структура папок соответствует пути в коде

### Структура весов

После загрузки структура должна выглядеть примерно так:
```
MLSD_Litvinov_AITH/
├── service/
│   ├── app.py
│   ├── requirements.txt
│   └── README.md
└── results/
    └── qwen-vl-regional/
        └── exp_r=16_alpha=32_seq=256_ne=25/
            └── checkpoint-430/
                ├── adapter_config.json
                ├── adapter_model.safetensors
                └── ...
```

## Запуск

Из папки `service` выполните:

```bash
streamlit run app.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`

## Использование

1. Загрузите изображение (JPG, PNG, WEBP)
2. Выберите готовый промпт или введите свой вопрос
3. Нажмите "Сгенерировать описание"
4. Получите описание изображения от модели

## Настройки

В боковой панели можно настроить:
- Путь к LoRA весам
- Максимальную длину генерируемого ответа (в токенах)

## Технические детали

- **Базовая модель:** Qwen2.5-VL-3B-Instruct
- **Fine-tuning:** LoRA (r=16, alpha=32)
- **Специализация:** Описание русских сказочных персонажей и общих объектов
- **Устройство:** Автоматический выбор (CUDA/MPS/CPU)

## Примечания

- При первом запуске модель будет загружена из HuggingFace (около 6GB)
- LoRA адаптеры загружаются из локальной папки
- Модель кэшируется с помощью `@st.cache_resource` для быстрых последующих запросов
